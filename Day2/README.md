# Day 2: Python Data Types, Variables & Indexing

This repository contains practical scripts covering core Python concepts including keywords, variable identifier rules, dynamic typing, primitive data types, string indexing, and formatted CLI user input.

## Key Concepts Covered

- **Keywords & Reserved Words:** Inspecting Python's built-in keywords using the `keyword` module.
- **Variables & Identifiers:** Naming rules, case-sensitivity, and valid identifier characters.
- **Core Data Types:** Integers, Floats, Strings, Booleans, and Complex Numbers (`10 + 67j`).
- **Dynamic Typing:** Variable reassignment across different data types at runtime.
- **String Operations:** Calculating length with `len()` and zero-based positional indexing.
- **User Input & String Formatting:** CLI table generator using `int(input())` and formatted strings.
