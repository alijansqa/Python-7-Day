# Day 4: Conditions, Loops, & Control Flow

## Overview
Day 4 of the Python challenge covers conditional branching (`if`, `elif`, `else`), iterative execution (`for` and `while` loops), control flow modifiers (`break`, `pass`), pattern matching (`match`/`case`), and practical algorithm applications.

## Key Concepts Covered
* **Conditional Branching:** Making decisions using `if`, `else`, and nested conditions.
* **Logical Operators:** Combining conditions using `and`, `or`.
* **Loops:** Iterating with `for` loops using `range()` (start, stop, step) and `while` loops.
* **Control Flow:** Using `break` to exit loops and `pass` as a placeholder.
* **Pattern Matching:** Using Python's `match`/`case` statement for clean conditional routing.
