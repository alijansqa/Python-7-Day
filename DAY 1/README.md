# Day 1: Python Basics & Syntax Fundamentals

This directory contains hands-on scripts covering fundamental Python concepts, including output formatting, arithmetic operations, user input handling, and type conversion.

## 📂 Code Files & Practice Breakdown

| Script | Topic | Description |
| :--- | :--- | :--- |
| `LAB001.py` | Basic Output | Using `print()` to display standard string messages to the console. |
| `LAB002.py` | Basic Arithmetic | Performing operations (`+`, `-`, `*`, `/`) and observing automatic float conversion on division. |
| `LAB003.py` | `print()` Formatting | Customizing console output using arguments like `sep` (separators) and `end` control characters (`\t`). |
| `LAB004.py` | User Input | Capturing console input using `input()` and storing values inside variables. |
| `LAB005.py` | Type Casting & Calculator | Converting string inputs to integers (`int()`) to build a basic command-line calculator. |

## 💡 Key Takeaways
* **Output Customization:** `sep="-"` changes the space between multiple printed values, while `end="\t"` controls line ending behavior.
* **Input Types:** `input()` returns data as a string by default. Arithmetic operations require explicit type casting using `int()`.
* **Division Result:** Division operations in Python 3 return floating-point numbers (`float`).
