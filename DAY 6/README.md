# DAY 6: Object-Oriented Programming (OOPs) in Python

This folder contains hands-on scripts exploring core Object-Oriented Programming concepts in Python, tailored for Software Quality Assurance (SQA) and test automation workflows.

---

## 📂 Lab Files Overview

* **`Lab042.py` - Classes & Objects Basics**
  * Introduction to class structures, attributes (`name = "Lambo"`), and object behavior methods (`drive()`)[cite: 8].
* **`Lab043.py` - Constructors (`__init__`)**
  * Implementing parameterized constructors (`__init__`) used heavily in API and web test automation frameworks to pass test data dynamically[cite: 9].
* **`Lab044.py` - Methods & Parameterized Object Creation**
  * Creating methods (`display()`) inside classes to process and output object state attributes[cite: 10].
* **`Lab045.py` - Encapsulation**
  * Protecting sensitive attributes using private variables (`self.__balance`) and safely modifying/accessing them via getter and setter methods (`get_balance()`, `deposit()`, `withdraw()`)[cite: 11].
* **`Lab046.py` - Single Inheritance**
  * Inheriting attributes and methods from a parent class (`Animal`) to a child class (`Dog`) to achieve code reusability[cite: 12].
* **`Lab047.py` - Multilevel Inheritance**
  * Demonstrating multi-generational inheritance chains (`Grandfather` $\rightarrow$ `Father` $\rightarrow$ `Son`) and method resolution[cite: 13].

---

## 🚀 Key Takeaways
* **Classes & Objects:** Blueprints versus instantiated instances.
* **Constructors:** Automatic initialization of data using `__init__`.
* **Encapsulation:** Data hiding to prevent unauthorized external access.
* **Inheritance:** Code extension and hierarchy mapping for clean automation architectures (foundational for Page Object Model patterns).
