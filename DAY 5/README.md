# Day 5: Functions, Data Structures, Lambda, & Recursion

## Overview
Day 5 of the Python challenge covers reusable code blocks, built-in vs user-defined functions, arguments, advanced data structures (Lists, Sets, Tuples, Dictionaries), anonymous lambda expressions, and recursive functions.

## Key Concepts Covered
* **Functions:** Built-in functions (`len()`, `max()`, `print()`) and user-defined functions using `def`[cite: 14].
* **Arguments:** Single arguments, positional parameters, and multiple arguments (`firstname`, `lastname`)[cite: 15].
* **Advanced Data Structures:** 
  * **Lists:** Ordered, mutable collections (`.append()`, `.remove()`)[cite: 16].
  * **Sets:** Unordered collections of unique items (`.add()`, `.remove()`)[cite: 17].
  * **Tuples:** Ordered, immutable collections of items[cite: 18].
  * **Dictionaries:** Unordered collections of key-value pairs[cite: 18].
* **Lambda Functions:** Small anonymous functions for short expressions and concise code mapping[cite: 19].
* **Recursion:** Functions calling themselves with a defined base exit condition[cite: 20].
