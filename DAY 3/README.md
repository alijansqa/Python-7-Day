# Day 3: Advanced Data Types, Methods, & Operators

## Overview
Continuing the 7-day Python challenge, Day 3 covers advanced core data structures, string manipulation, type casting, numeric literals, and arithmetic operations essential for validation scripting and automation.

## Key Concepts Covered
* **String Functions & Methods:** Manipulation including `.capitalize()`, `.lower()`, and `.count()`[cite: 9].
* **Immutability & Slicing:** Understanding string permanence, index access, positive/negative slicing, and `len()`[cite: 10].
* **Lists:** Collections, indexing, nested structures, item assignment limits, and `len()` operations[cite: 11].
* **Type Conversion:** Converting between data types (e.g., `list(string)`)[cite: 12].
* **Escape Sequences:** Formatting output with `\n`, `\t`, `\r`, `\b`, and raw strings (`r""`)[cite: 13, 14].
* **Numeric Literals & Operators:** Working with binary, octal, hexadecimal, floats, complex numbers, and arithmetic/assignment operators (`+`, `-`, `*`, `/`, `**`)[cite: 15, 16, 17].
